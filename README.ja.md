## 宣言

2022 年 11 月、ChatGPT が生まれた。その日から、すべてが偽造できる世界で、「本物」はぜいたく品になった。

AI はどんな文体も模倣できる——だが、あなたが打った時間だけは偽造できない。検出器は推測する。RealTrace は証明する。

RealTrace は、人間の創作であることを証明する**実在証明システム**だ。最初の一文字を打ち込んだ瞬間から、一瞬の間も、削除の跡も、打鍵のリズムも、すべてリアルタイムに記録され、Ed25519 署名によって改ざん不能な創作チェーンに鎖される。書き終えたとき、あなたは `.rt` チェーンファイルを手にする——検証可能、追跡可能、改ざん不能。

**これはもう、選択問題ではない。** すべての封緘は直前の封緘のハッシュを参照する。因果の順序は暗号技術で固定され、後からの修正は数学的に検出できる。これは統計モデルの推測ではなく、物理と数学が与えた証拠だ。

**あなたは作者だ。証拠を持つ権利がある。** 「これ、AI が書いたんじゃない？」と問われたとき、言い訳だけで済ませるべきじゃない。RealTrace は独立に検証できる実在証明を渡す——投稿にも、権利主張にも、立証にも。創作者は素手で戦うべきではない。

**あなたの内容は、永遠にあなたのもの。** 本文は決してデバイスを離れない。チェーンに記録されるのはハッシュと行動特徴だけ。「プライバシーを守ります」と約束するのではない——アーキテクチャ上、内容に触れることが不可能なのだ。打刻も、検証も、証明書の確認も、すべてオフラインで完結する。サイトが閉じても、チェーンは生き続ける。

**信頼は、プラットフォーム自身が決めるべきではない。** 子チェーンのルートハッシュは公式創世チェーンにアンカーされる。どのプラットフォームで署名されたチェーンも、同じ公開アンカーまで遡って、独立に監査できる。

RealTrace はオープンソースだ。個人は無料。すべての創作者が、自分の作品に封緘を押せる。

**あなたの創作。あなたの実在証明。**

## 人間の創作が「囲い込み」の対象になった

2026 年 7 月、裁判所で開封された文書が Anthropic の「Project Panama（パナマ計画）」の実態を明らかにした。中古書店を通じて実物の古書を 100 万冊以上まとめ買いし、油圧プレスで背表紙を切り落とし、1 ページずつスキャンしたうえで原本を廃棄する——すべては Claude に「人間が手で書いた文字」をもっと読ませるためだ。別の訴訟では、無許諾の約 700 万冊が学習に使われ、15 億ドルの和解金で決着した。米国の著作権訴訟では過去最高額となる。

AI 企業は人間の創作を囲い込んでいる。彼らは誰よりもよく知っているからだ。モデルは無限に生成できるが、人間の思考・経験・選択は有限である、と。古書は買い尽くされ、スキャンされ、廃棄されていく。一方、新しい世代が書いた言葉は AI の洪水に埋もれ、「これは私が書いた」と証明することさえできない。

人間の創作が希少な資源になるなら、それは証明され、守られる必要がある。

真跡がやっているのは、まさにこのことだ。書き始めた瞬間から、創作の過程を検証可能で改ざん不能な署名チェーンに閉じ込める。あなたの文章は常にあなたのもの。あなたの創作には、実在証明がある。

**人間の創作が希少になる時代、真跡こそがその証明だ。**

## なぜ RealTrace なのか

2022 年 11 月、ChatGPT が生まれた。その日から、インターネット上のすべてが「信頼できない」ものになった：ニュース、コメント、論文、詩、コード、契約書、訴状——作者自身を含め、誰も肉眼では、ある文章が人間のものか機械のものかを判別できなくなった。

「AI がものを書ける」より恐ろしいのは、**すべてが偽造できるとき、本物がぜいたく品になる**ことだ。人間の創作の価値は音もなく薄められていく——あなたの思考、感情、経験、選択は、機械の出力と区別できないテキストになっていく。

RealTrace がやろうとしているのは、「人間の創作」に暗号学的な**実在証明**を与えることだ：

- **最初の一文字から**：「これは私が書いた」という事後的な主張ではなく、創作プロセスをリアルタイムに記録し、リアルタイムに署名する；
- **プラットフォームの信用に依存しない**：すべての署名はオフラインで独立に検証でき、数学的に監査可能；
- **コンテンツ非アップロード**：本文は常にあなたの手元に。チェーンに記録されるのはハッシュと行動特徴だけ。

> AI がすべてを模倣できる時代に、人間の創作の尊厳は守られるべきだ。

| 問題 | RealTrace の解決策 |
|:--|:--|
| AI 生成コンテンツと人間の創作を区別できない | リアルタイム打刻：執筆中に Ed25519 署名スタンプを自動生成し、打鍵リズム・間・削除量などの行動特徴を記録 |

## コア原理

**署名チェーン（スタンプチェーン）**——執筆中のすべての封緘が、署名チェーン上のノードになる：

```text
chainHash = SHA-256(sessionId || index || salt || timestamp || contentHash || prevChainHash || nonce)
signature = Ed25519_sign(chainHash)
```

- **因果順序は偽造できない**：各スタンプのハッシュが直前のスタンプを参照し、チェーンのトポロジー順序は `prevChainHash` で決まる。システム時刻とは無関係で、後から挿入・並べ替えは不可能；
- **秘密鍵は偽造できない**：Ed25519 署名はローカル生成の秘密鍵で行われ、秘密鍵はデバイスの外に出ない；
- **行動指紋**：各スタンプに打鍵リズム / 間 / 削除量の特徴（HMAC 行動チェーン）を添付し、信頼度分析に供する；
- **創世チェーン・アンカリング**：子チェーン鍵は公式シードから HKDF-SHA256 で決定的に派生。子チェーン根ハッシュは公式創世チェーンにアンカーされ、上にも下にも追跡可能（個人無料）。
- **全文 Merkle バインド**：各封緘が全文の Merkle ルートを計算してチェーンに書き込み、全文を公開せずに任意の段落を選択的に開示できる。

**チェーンファイル形式（`.rt`）**：ZIP コンテナで、`chain.json`（署名チェーン）と `meta.json`（バージョン・時刻・証明書メタデータ）を含む。チェーンは「創作プロセスの証拠」だけを記録し、本文は含まない。

詳細は [`docs/chain-spec.md`](docs/chain-spec.md) と [`docs/rt-file-format.md`](docs/rt-file-format.md)。

## クイックスタート

### 1. ライティングツールをローカルで開く（サーバー不要）

`writer/index.html` をダブルクリックするか、任意の静的サーバーでリポジトリ直下を配信する：

```bash
npx serve .
# http://localhost:3000/writer/ を開く
```

- 執筆前に「匿名執筆」または「.rt インポートで続行」を選択してから執筆枠へ。入力すると自動で打刻されます；
- 「封章・上链」をクリックして確定すると、オフライン検証ページへ移動し、`.txt` 原文と `.rt` チェーンファイルをダウンロードできます（純ローカル出力、アップロードなし）；
- `verify/index.html` を開いて `.rt` ファイルをドラッグすると、完全オフラインでチェーンの完全性を検証できます。

### 2. 公式創世チェーン・アンカリングを有効化（任意、個人無料）

```bash
copy config.example.js config.js
```

`config.js` を編集：

```js
window.RT_CONFIG = {
  anchor: {
    apiBase: "https://公式アンカーサービスURL",   // 公式発表に準拠
    genesisPublicKey: "公式創世チェーン根公開鍵",
    enabled: true                                 // 封緘時にチェーン根を提出
  }
};
```

> `config.js` は `.gitignore` で無視されるため、自分のエンドポイント設定を誤ってコミットすることもありません。
> 個人創作の上链は**無料**。企業 / プラットフォーム連携はライセンス契約（商業連携は公式まで）。

### 3. テストを実行

```bash
npm test
```

## 本バージョンの機能（v0.2.0）

本リポジトリは **MVP 最小版**：最小のコードで「執筆 → 打刻 → 封緘 → 検証」の完全ループを実装する。本バージョンには以下が含まれる：

- **リアルタイム打刻**：執筆中に Ed25519 署名スタンプを自動生成し、打鍵リズム・間・削除量などの行動特徴を記録；
- **改ざん防止チェーン**：各スタンプが直前のスタンプのチェーンハッシュを参照し、後からの修正は数学的に検出可能；
- **コンテンツ非アップロード**：本文はローカルのみ。チェーンにはコンテンツハッシュと行動特徴だけを記録；
- **オフライン検証**：`.rt` チェーンファイルはサーバー依存なしで完全にオフライン検証可能；
- **行動指紋**：打鍵リズム / 間 / 削除量の特徴（HMAC 行動チェーン）で信頼度分析；
- **創世チェーン・アンカリング（任意、個人無料）**：封緘後、チェーン根ハッシュを公式創世チェーンに提出し、公開監査可能な来歴を形成；
- **バージョン追跡**：`.rt` パッケージは `meta.json` に `appVersion`、`chain.json` にチェーン形式 `version` を記録し、上链時にバージョンを保持。
- **Merkle 選択的開示**：各封緘が全文 Merkle ルートをバインド。全文を公開せずに任意の段落だけを開示可能；
- **開示証明の生成**：オフライン検証ページで段落の開示証明をワンクリック生成、Merkle パス可視化付き、JSON コピーで自己証明；
- **6言語UI**：執筆ページ / オフライン検証ページ / 公式サイトが 简体中文 · English · 日本語 · 한국어 · Deutsch · Français に対応；
- **チェーンID命名規則**：公開鍵 + ルートハッシュを双バインドした23桁のチェーンID（`web-personal-…`）。検証可能・逆算不可；
- **執筆モード選択**：執筆前に「匿名執筆」または「.rt インポートで続行」を選択。続行時は元のチェーンを自動延長。
- **タイムラインのモジュール化**：拡大縮小可能なヒストグラム・タイムラインを共通モジュール `core/rt-timeline.js` に分離し、執筆リズムを一目で確認可能。

> 完全な変更履歴: [CHANGELOG.md](CHANGELOG.md)。

すべての機能は後方互換を維持：旧バージョンが生成した `.rt` チェーンファイルは、以降のバージョンでも検証・追跡できなければならない。

## ユースケース

- **創作者の投稿**：「これ、AI が書いたんじゃない？」と疑われたとき、`.rt` 実在証明ひとつで創作プロセスを説明できる——文字数、所要時間、創作リズム、誰でも検証可能；
- **著作権の権利主張**：立証はもう口先だけの主張ではない。チェーン上の行動指紋と署名チェーンが、創作プロセスの監査可能な証拠を提供する；
- **出版社 / コンテンツコミュニティ**：投稿が本当に人間によるリアルタイム創作か、後から貼り付けや機械の一括生成でないかを検証；
- **学術シーン**：論文・課題・技術文書の創作プロセス証拠を添えることで、「私が書いた」に拠り所を持たせる。

> 創作者は、疑いに素手で立ち向かうべきではない。

## プライバシーとセキュリティ

- デフォルトで**コンテンツ非アップロード**：執筆内容はローカルのみ。チェーンにはコンテンツハッシュと行動特徴だけを記録；
- `.rt` チェーンファイルは完全にあなたの管理下にあり、ローカル保管または自己暗号化バックアップが可能；
- 公式アンカリングはチェーン根ハッシュと署名メタデータのみを提出し、本文は提出しない；
- すべての検証ロジックはオープンソースで、自ら監査可能；
- セキュリティ脆弱性を発見したらメンテナーに直接連絡し、修正前の公開開示はしないこと。
