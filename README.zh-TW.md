## 宣言

2022 年 11 月，ChatGPT 誕生。從那一天起，當一切都可以被偽造，真實反而成了奢侈品。

AI 可以模仿任何風格——除了你打字的時間。檢測器在猜，真跡在證明。

真跡是一套**人類創作在場認證系統**：從你落筆第一秒起，每一次停頓、每一段刪改、每一個字的節奏，都被實時記錄，並用 Ed25519 簽名鎖進一條不可篡改的創作鏈。寫完的那一刻，你拿到一份 `.rt` 鏈文件——可驗證、可溯源、不可篡改。

**這不再是一道選擇題。** 每個封章都引用前一個封章的哈希，因果序由密碼學鎖死，任何回顧性修改在數學上可檢測。這是物理與數學給的證據，不是統計模型的猜測。

**你是原創者，你該有證據。** 被質疑「這是不是 AI 寫的」的時候，不該只能解釋。真跡給你一份可以獨立驗證的在場證明——投稿、維權、舉證，創作者不該赤手空拳。

**你的內容，永遠只屬於你。** 正文永遠留在你的設備上，鏈上只記錄哈希與行為特徵。不是我們承諾保護隱私，是架構上根本拿不到你的內容——打章、驗章、證書驗證全部離線完成，關站也不失效。

**信任，不該由平臺自己說了算。** 子鏈根哈希錨定進官方創世鏈，任何平臺簽出的鏈都能回溯到同一個公開錨點，獨立審計。

真跡開源，個人免費。每個創作者都可以為自己的創作封章。

**你的創作，你的在場證明。**

## 當人類創作，開始被囤積

2026 年 7 月，法庭解封的文件揭開了 Anthropic 的「巴拿馬計劃」：通過二手書商批量收購上百萬冊實體舊書，用液壓機切下書脊、逐頁掃描，再銷燬原書——為的只是讓 Claude 多讀到一些「人類親手寫的字」。另一案中，未經授權的約 700 萬冊圖書被用於訓練，最終以 15 億美元達成和解，創下美國版權案紀錄。

AI 公司正在囤積人類創作。因為它們比任何人都清楚：模型可以無限生成，人類的思考、經歷與選擇，是有限的。舊書會被買光、掃完、銷燬；新一代人類寫下的內容，卻淹沒在 AI 的洪流裡，甚至無法證明「這是我寫的」。

當人類創作成為稀缺品，它就更需要被證明、被守護。

真跡做的，正是這件事：從你落筆的第一秒起，把創作過程鎖進可驗證、不可篡改的簽名鏈。你的文字始終屬於你，你的創作有在場證明。

**當人類創作成為稀缺品，真跡就是它的在場證明。**

## 核心原理

**簽名鏈（stamp chain）**——寫作過程中的每一次封章，都是簽名鏈上的一個節點：

```text
chainHash = SHA-256(sessionId || index || salt || timestamp || contentHash || prevChainHash || nonce)
signature = Ed25519_sign(chainHash)
```

- **因果序不可偽造**：每個 stamp 的哈希都引用前一個 stamp，鏈的拓撲順序由 `prevChainHash` 決定，與系統時間無關，無法事後插入或重排；
- **私鑰不可偽造**：Ed25519 簽名由本地產出的私鑰完成，私鑰不出本地；
- **行為指紋**：每個 stamp 附帶打字節奏 / 停頓 / 刪除量特徵（HMAC 行為鏈），供可信度分析；
- **創世鏈錨定**：子鏈密鑰由官方種子經 HKDF-SHA256 確定性派生，子鏈根哈希錨定進官方創世鏈，向上可回溯、向下可溯源（個人免費）。
- **Merkle 全文綁定**：每次封章同時計算全文 Merkle 根並寫入鏈，支持後續選擇性披露任意段落而不暴露全文。

**鏈文件格式（`.rt`）**：ZIP 容器，內含 `chain.json`（簽名鏈）與 `meta.json`（版本、時間、證書元數據）。鏈只記錄「創作過程證據」，不包含正文。

詳見 [`docs/chain-spec.md`](docs/chain-spec.md) 與 [`docs/rt-file-format.md`](docs/rt-file-format.md)。

## 快速開始

### 1. 本地打開寫作工具（無需服務器）

直接雙擊 `writer/index.html`，或任意靜態服務器託管本倉庫根目錄：

```bash
npx serve .
# 打開 http://localhost:3000/writer/
```

- 進入寫作頁先選擇「匿名寫作」或「導入 .rt 續寫」，再進入寫作框；輸入內容即自動打章；
- 點擊「封章上鍊」確認封章，跳轉離線認證頁，可下載 `.txt` 原文與 `.rt` 鏈文件（純本地導出，內容不上傳）；
- 打開 `verify/index.html` 拖入 `.rt` 文件，即可全離線驗證鏈的完整性。

### 2. 啟用官方創世鏈錨定（可選，個人免費）

```bash
copy config.example.js config.js
```

編輯 `config.js`：

```js
window.RT_CONFIG = {
  anchor: {
    apiBase: "https://官方錨定服務地址",   // 以官方發佈為準
    genesisPublicKey: "官方創世鏈根公鑰",
    enabled: true                          // 封章時提交鏈根上鍊
  }
};
```

> `config.js` 已被 `.gitignore` 忽略，包含你自己的端點配置也不會誤提交。
> 個人創作上鍊**免費**；企業 / 平臺合作按授權（商業合作請聯繫官方）。

### 3. 運行測試

```bash
npm test
```

## 本版本包含哪些功能（v0.4.0）

本倉庫是 **開源完整版**：實現「寫作 → 打章 → 封章 → 驗證 → 身份續寫 → 鏈合併」完整閉環。本版本已包含：

- **實時打章**：寫作過程中自動生成 Ed25519 簽名 stamp，記錄打字節奏、停頓、刪除量等行為特徵；
- **防篡改鏈**：每個 stamp 引用前一個 stamp 的鏈哈希，任何回顧性修改在數學上可檢測；
- **零內容上傳**：正文只存在本地，鏈上僅記錄內容哈希與行為特徵；
- **離線驗證**：`.rt` 鏈文件可完全離線驗證，不依賴任何服務器；
- **行為指紋**：打字節奏 / 停頓 / 刪除量特徵（HMAC 行為鏈），供可信度分析；
- **創世鏈錨定（可選，個人免費）**：封章後提交鏈根哈希到官方創世鏈，形成公開可審計溯源；
- **版本可溯源**：`.rt` 包內 `meta.json` 記錄 `appVersion`，`chain.json` 記錄鏈格式 `version`，封章上鍊時攜帶版本號。
- **Merkle 選擇性披露**：每章綁定全文 Merkle 根，可只披露任意段落而不暴露全文；
- **生成披露證明**：離線認證頁一鍵生成段落披露證明，附 Merkle 路徑可視化，複製 JSON 即可自證；
- **六語界面**：寫作頁 / 離線認證頁 / 官網支持 簡體中文 · English · 日本語 · 한국어 · Deutsch · Français；
- **鏈 ID 命名規則**：公鑰 + 根哈希雙綁定的 23 位鏈 ID（`web-personal-…`），可驗證、不可反推；
- **創作模式選擇**：進入寫作前選擇「匿名寫作」或「導入 .rt 續寫」，續寫自動延續原鏈並同步狀態欄。
- **時間軸模塊化**：可縮放直方圖時間軸剝離為獨立共用模塊 `core/rt-timeline.js`，寫作節奏一目瞭然。

- **創世鏈錨定隊列**：封章後鏈元數據先入本地隊列，聯網自動補傳；Ed25519 簽名（`chainId|rootHash`）防冒領；
- **上鍊隊列面板（六語）**：寫作頁 ⛓ 狀態指示 / 一鍵手動同步 / 自動同步開關，保持零內容上傳；
- **隱私須知更新**：明確說明封章後僅鏈元數據可能同步至創世鏈，可在「⛓」面板關閉自動同步。

- **身份模塊**：PBKDF2-SHA256（60 萬次迭代）+ AES-256-GCM 加密身份密鑰；可導出/導入 `.rtkey` 身份密鑰文件，導入帶身份的 `.rt` 用密碼恢復創作者身份，封章自動嵌入加密身份，同一密鑰可持續續寫原鏈；
- **鏈格式 v3 合併語義**：同密鑰續寫自動延續原鏈（`mergeChainsVerified` 重籤驗證）；跨密鑰可聚合為容器（`aggregateChains`），逐子鏈獨立驗證；
- **跨瀏覽器驗證器**：tweetnacl 統一驗籤，WebCrypto 僅作回退，驗證結果各瀏覽器一致。

> 完整變更記錄見 [CHANGELOG.md](CHANGELOG.md)。

所有功能保持向後兼容：舊版本生成的 `.rt` 鏈文件在後續版本必須可驗證、可追溯。

## 使用場景

- **創作者投稿**：作品被質疑「這是不是 AI 寫的」時，一份 `.rt` 在場證明就能說明創作過程——字數、耗時、創作節奏，人人可核對；
- **版權維權**：舉證不再是口頭聲明。鏈上的行為指紋與簽名鏈，為原創過程提供可審計的證據；
- **出版方 / 內容社區**：核驗投稿是否為真人實時創作，而不是事後粘貼或機器批量生成；
- **學術場景**：論文、課題、技術文檔的原創過程佐證，讓「我寫的」有據可查。

> 創作者不該赤手空拳地面對質疑。
