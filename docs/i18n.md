# README Internationalization Policy

## English is the single source of truth

`README.md` (English) is the **authoritative** version of the project README. All other
`README.<lang>.md` files are translations derived from it.

## Rules

1. **Content changes are made in `README.md` first.** Never edit a translation to change product facts, features, links, or version info — those changes belong in the English source.
2. Every translation file starts with an HTML comment pointing to the English source.
3. The language switcher bar and version badges must stay identical across all 14 files.
4. Language codes follow GitHub / Linguist conventions (`zh-TW`, `pt-BR`, ...).
5. The demo media in non-Chinese translations points to the English demo (`realtrace-demo-25s-en.*`); Chinese variants use `-zh`.

## How to add or update a translation

1. Update `README.md` (English).
2. Generate or update `README.<lang>.md` from it — machine translation as a first pass, then a native-speaker review before release.
3. Update the language switcher bar in **all** files (including the new one).
4. Bump the version in all README badges, `package.json`, and `CHANGELOG.md` on release.
