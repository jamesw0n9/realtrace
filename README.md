# Realtrace · 真迹

> 为每一份人类创作留下不可伪造的「在场证明」。
> Ed25519 签名链 · 实时打章 · 离线验证 · 官方创世链锚定（个人免费）

Realtrace 用密码学签名链证明"内容确实是人类实时写出来的"，而不是 AI 生成的：
- **实时打章**：写作过程中每隔一段时间自动生成一个加密签名（stamp），记录打字节奏、字符变化等行为特征；
- **防篡改链**：每个 stamp 引用前一个 stamp 的哈希，任何回顾性修改在数学上可检测；
- **完全离线可用**：打章、验章全部在本地完成，内容不上传服务器；
- **官方创世链锚定（可选，个人免费）**：封章后把子链根哈希提交到官方创世链，形成可公开审计的溯源记录。

## 快速开始

### 1. 本地打开写作工具（无需服务器）

直接双击 `writer/index.html`（或任意静态服务器托管本仓库根目录）：

```
npx serve .
# 打开 http://localhost:3000/writer/
```

- 输入内容即自动打章；点击「封章上链」下载 `.rt` 链文件 + `.txt` 内容文件；
- 打开 `verify/index.html` 拖入 `.rt` 文件，即可全离线验证链的完整性。

### 2. 启用官方创世链锚定（可选，个人免费）

```
copy config.example.js config.js
```

编辑 `config.js`：

```js
window.RT_CONFIG = {
  anchor: {
    apiBase: "https://官方锚定服务地址",   // 以官方发布为准
    genesisPublicKey: "官方创世链根公钥",
    enabled: true                          // 封章时提交链根上链
  }
};
```

> `config.js` 已被 `.gitignore` 忽略，包含你自己的端点配置也不会误提交。
> 个人创作上链**免费**；联合授权平台使用**单独支链**并另行授权（商业合作请联系官方）。

### 3. 运行测试

```
npm test
```

## 功能特性

- **实时打章**：写作过程中自动生成 Ed25519 签名 stamp，全程离线可用；
- **防篡改链**：每个 stamp 引用前一个链哈希，任何回顾性修改在数学上可检测；
- **零内容上传**：正文只存在本地，链上仅记录内容哈希与行为特征；
- **离线验证**：`.rt` 链文件可完全离线验证，不依赖任何服务器；
- **行为指纹**：记录打字节奏 / 停顿 / 删除量等特征（HMAC 行为链），供可信度分析；
- **创世链锚定（可选，个人免费）**：封章后提交链根哈希到官方创世链，形成公开可审计溯源。

## 技术原理（摘要）

- **链哈希（F2）**：`chainHash = SHA-256(sessionId || index || salt || timestamp || contentHash || prevChainHash || nonce)`
- **签名**：Ed25519 对链哈希摘要字节签名，跨端（前端 / 离线验证器 / 服务端）行为一致
- **行为特征**：每章附带打字节奏 / 删除量 / 停顿特征（HMAC 行为链），供可信度分析
- **创世链**：子链密钥由官方种子 HKDF-SHA256 确定性派生；子链根哈希锚定进官方创世链，公开可审计

详见 [`docs/chain-spec.md`](docs/chain-spec.md) 与 [`docs/rt-file-format.md`](docs/rt-file-format.md)。
版本迭代计划见 [docs/ROADMAP.md](docs/ROADMAP.md)。

## 隐私与安全

- 默认**零内容上传**：写作内容只存在于本地，链上只记录内容哈希与行为特征；
- `.rt` 链文件完全由你掌控，可本地保管或自行加密备份；
- 官方锚定仅提交链根哈希与签名元数据，不提交正文；
- 所有验证逻辑开源，可自行审计。
