# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub Private Vulnerability Reporting:

https://github.com/jamesw0n9/realtrace/security/advisories/new

Do **not** open a public issue for security findings. Include:

- Affected version(s)
- Steps to reproduce
- Impact assessment
- Suggested fix (optional)

## Response SLA (best effort, small project)

- Acknowledgement: within 48 hours
- Critical/high: fix target within 7 days
- Medium: fix target within 30 days

## Scope

In scope: the open-source code in this repository (`core/`, `writer/`, `verify/`, `anchor/`, `site/`).

Out of scope: production server configuration, private identity files (`.rtkey`), and user-generated content.
